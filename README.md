# sleek-firefox-profile
A simple, clean, private and usable Firefox profile
# Features
## Annoyances
- Disabled firefox intro tabs on the first start
- Disable new page tab intro
- Disable pocket reading list
- Disable sponsored top sites
- Disable `about:config` warning
- Disable trimming of URLs
- Disable checking if firefox is default browser
- Disable reset prompt
- Disable Heartbeat userrating
- Empty new tab page
- Disable autoplay of  `<video>` tags
