# sleek-firefox-profile

A simple, clean, private, and usable Firefox profile.

## Features

### Annoyances

- **Disabled Firefox intro tabs on first start**  
  Removes the first-run tabs advertising the latest Firefox features.
- **Disabled new tab page intro**  
  Removes the introductory walkthrough on the new tab page during the first run.
- **Disabled Pocket reading list**  
  Disables the Pocket reading list integration by default.
- **Disabled sponsored top sites**  
  Removes [sponsored top sites](https://support.mozilla.org/en-US/kb/sponsor-privacy) (introduced in Firefox 83) that appear as ad suggestions in the URL bar.
- **Disabled `about:config` warning**  
  Skips the warning prompt when opening `about:config`.
- **Disabled URL trimming in the navigation bar**  
  Shows full URLs instead of hiding the `http://` prefix and trailing `/` slash.
- **Disabled default browser check**  
  Prevents Firefox from checking if it is set as your default browser on startup.
- **Disabled profile reset prompt**  
  Stops Firefox from asking to reset your profile if the browser hasn't been used in a while.
- **Disabled Heartbeat user ratings**  
  Disables Mozilla's [Heartbeat](https://wiki.mozilla.org/Firefox/Shield/Heartbeat) feedback prompts.
- **Empty new tab page**  
  Provides a clean, minimal new tab page.
- **Disabled `<video>` autoplay**  
  Prevents `<video>` elements from playing automatically. *(Note: On some video sites, you may need to click pause and play again to start playback.)*
